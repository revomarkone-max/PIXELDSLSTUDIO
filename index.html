📋 LLM Prompt Builder & CLI Workflow (SKILL.md v2)

For headless generation from any LLM CLI, run python pixeldsl.py sprites/my_sprite.json (or pipe via stdin). It validates edges/centering, prints a TrueColor ANSI preview in the terminal, exports PNGs to game_ready/, and syncs the sprite to this Web Studio!
